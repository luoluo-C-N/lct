# 独立悬浮伴侣与本地皮肤库设计

**日期：** 2026-07-30

**状态：** 已完成交互与视觉确认，等待书面规格审阅

**目标分支：** `feat/magic-image-library`

## 目标

把当前嵌在主资料库中的 `CompanionWindow` 支造成真正独立的 Windows 桌面悬浮窗口，并交付一个安全、可持久化的本地皮肤库。

本轮完成后：

- 应用启动时同时显示主资料库和独立悬浮伴侣。
- 悬浮伴侣始终置顶、无边框、可拖动，并记住最后位置。
- 用户可以从悬浮伴侣执行导入、截图、打开资料库和快速切换皮肤。
- 主资料库包含完整皮肤库，可管理三套内置皮肤以及本地导入的 PNG、WebP 和 ZIP 皮肤。
- 三套内置皮肤均具有已确认的球体结构与动态效果。
- 完成自动化测试、Windows 桌面冒烟验证、提交和同步后停止开发。

## 非目标

本轮不实现：

- 公共皮肤社区、账号、上传、下载、评分、审核或云端分发。
- 直接引用用户电脑上的外部皮肤路径。
- 可执行 HTML、CSS、JavaScript、WebAssembly 或远程资源皮肤。
- 皮肤商店、付费皮肤或跨设备皮肤同步。
- 云同步、独立安装包、签名和自动更新。

这些方向保留为未来需求，但必须另写规格与计划。

## 窗口架构

Tauri 启动时创建两个真实窗口：

### 主窗口 `main`

- 保留现有资料库界面。
- 增加“皮肤库”视图。
- 增加“显示/隐藏悬浮助手”入口。
- 关闭主窗口按现有应用退出逻辑处理。

### 悬浮窗口 `companion`

- 初始内容尺寸约 `72 × 72` CSS 像素。
- 透明、无系统边框、不可由用户调整尺寸。
- 始终置顶并跳过任务栏。
- 应用启动时自动显示。
- 用户可以从球体可交互区域拖动窗口。
- 拖动结束后保存逻辑位置与显示器信息。
- 重启后恢复最后位置；显示器消失、缩放变化或位置越界时，将窗口钳制回当前工作区。
- 关闭悬浮窗只隐藏，不退出应用；主窗口可以再次显示。

两个窗口复用同一套 React 构建。入口根据 Tauri 窗口标签渲染主资料库或悬浮伴侣，不复制第二套前端项目。

## 收起与展开

收起状态只显示球体与外侧光弧。

点击球体后，同一个 `companion` 窗口展开为约 `232 × 320` 的操作面板，包含：

- 导入图片。
- 全屏截图、区域截图和窗口截图。
- 打开或聚焦主资料库。
- 最近使用皮肤的快速切换。
- 打开主资料库“皮肤库”页面。
- 隐藏悬浮助手。

展开方向必须根据当前屏幕边缘向可见工作区内部选择，不能让面板超出屏幕。再次点击球体、点击面板外部或按 Escape 后收回。

展开或收回不改变球体在桌面上的视觉锚点。窗口尺寸变化后重新计算位置，以保持球体看起来停留在原处。

## 视觉基准

三套内置皮肤采用同一结构：

- 紫蓝、珍珠或青蓝材质球体。
- 中央四角星标。
- 五颗左右稀疏星点。
- 两段不闭合的外侧光弧。
- 柔和球面高光、边缘描线和低对比阴影。

不采用银河带、满球星云或复杂宇宙流体方案。

### 静谧极光

- 紫蓝球面。
- 奶油金中央星标。
- 紫金外弧追光。
- 与现有魔法书深色视觉保持一致。

### 雾白珍珠

- 珍珠母贝球面。
- 香槟金追光。
- 更轻、更明亮，适合浅色桌面。

### 深海墨色

- 青蓝玻璃球面。
- 冷色星光和青色追光。
- 在暗色桌面保持清晰边缘与较低亮度。

三套皮肤必须各自拥有完整材质和色谱定义，不能只对同一图层使用简单色相旋转。

## 动效

默认开启“柔和流光”：

- 外侧两段光弧显示连续追光，两层以不同速度、相反方向移动。
- 球面内部有低对比柔光缓慢横向流过。
- 稀疏星点错峰微闪。
- 中央星标做小幅呼吸。
- 悬停时追光和球面流光略微加速、亮度略微提高。
- 导入或截图进行中时转为不抢眼的呼吸式进度光。
- 成功时完成一次柔和脉冲，并在约 `1.2` 秒内恢复空闲。
- 失败时只出现一次低强度暖色脉冲，不循环闪烁。
- 不播放持续弹跳、突然缩放、强闪烁或声音。

动画只使用 `transform`、`opacity`、合成层渐变和有限的滤镜变化，避免持续重绘大图。

用户可以关闭动效。系统启用 `prefers-reduced-motion: reduce` 时必须停止追光、流光、呼吸和闪烁，只显示静态球体与清晰焦点状态。

## 主资料库皮肤库

主窗口新增“皮肤库”视图：

- 网格展示三套内置皮肤和本地导入皮肤。
- 每张卡片显示动态预览、名称、来源和使用状态。
- 点击卡片切换当前皮肤。
- 提供 PNG、WebP 和 ZIP 导入。
- 本地导入皮肤可以重命名、调整流光颜色、速度和强度，以及删除。
- 内置皮肤不可删除或覆盖。
- 删除当前皮肤时先切换回“静谧极光”，再删除文件和记录。
- 提供全局柔和流光开关。

悬浮面板只承担快速切换和跳转，不承载完整管理，避免长期遮挡桌面。

## 统一皮肤模型

Rust 管理统一的 `CompanionSkin`：

- `id`
- `name`
- `source`：`builtin`、`image` 或 `package`
- `visual_preset`
- `texture_path`
- `preview_path`
- `flow_colors`
- `flow_speed`
- `flow_intensity`
- `created_at`

当前皮肤、动效开关、悬浮窗口可见性和最后窗口位置存入本地设置。

皮肤文件存放在：

```text
$APPLOCALDATA/skins/<skin-id>/
```

前端只通过受限 asset protocol 读取皮肤预览和纹理。协议 scope 增加 `$APPLOCALDATA/skins/**/*`，不扩大到整个本地数据目录。

## PNG 与 WebP 导入

- 单文件最大 `10 MiB`。
- 解码后尺寸范围为 `128 × 128` 至 `4096 × 4096`。
- 非正方形图片使用居中裁剪生成方形纹理和预览，原始导入文件不直接引用。
- Rust 实际解码图片，不只信任扩展名或 MIME。
- 导入后复制到应用数据目录；用户移动或删除源文件不影响皮肤。
- 应用从缩小后的像素样本提取主色，降低饱和度并钳制亮度，生成安全的流光色谱。
- 无法得到合适色谱时使用静谧极光的薰衣草色作为回退。

## ZIP 皮肤包

ZIP 最大压缩体积 `20 MiB`，最大解压体积 `40 MiB`，最多 `16` 个条目。

根目录必须包含不超过 `64 KiB` 的 `manifest.json`：

```json
{
  "version": 1,
  "name": "My Skin",
  "texture": "texture.webp",
  "flowColors": ["#B79CFF", "#FFE4B5"],
  "flowSpeed": 1.0,
  "flowIntensity": 0.7
}
```

允许内容：

- 一个 `manifest.json`。
- PNG 或 WebP 纹理与预览资源。

禁止内容：

- 绝对路径、`..`、符号链接和路径穿越。
- HTML、CSS、JavaScript、可执行文件、字体、SVG、音频、视频和远程 URL。
- 未在 manifest 中引用的多余文件。
- 超出数量、大小、维度和参数范围的内容。

导入流程先解压到临时目录并完整验证，再原子移动到最终皮肤目录并写入记录。任何失败都必须清理临时目录，不留下半导入皮肤。

`flowSpeed` 与 `flowIntensity` 在应用定义的安全范围内钳制。皮肤包不能改变动画类型、窗口权限或应用代码。

## 命令与事件

Rust 提供最小命令边界：

- 列出皮肤。
- 导入图片皮肤。
- 导入 ZIP 皮肤。
- 更新本地皮肤设置。
- 设置当前皮肤。
- 删除本地皮肤。
- 读取与更新悬浮窗口设置。
- 显示、隐藏、展开、收回和聚焦应用窗口。

所有窗口命令必须只操作已知标签 `main` 和 `companion`，不接受任意窗口标签。

跨窗口事件：

- `companion-skin-changed`
- `companion-settings-changed`
- `companion-visibility-changed`

事件负载必须包含提交后的完整状态。两个前端入口订阅事件并在卸载时释放监听器。

## 错误处理

- 导入错误在皮肤库中以可恢复的 `role="alert"` 显示，原皮肤保持选中。
- 非法 ZIP 明确区分格式版本、路径、文件类型、大小、图片解码和 manifest 字段错误。
- 皮肤切换只在记录和文件均可用后提交；失败不改变当前皮肤。
- 删除失败时保留记录和文件，并提示重试。
- 当前皮肤文件丢失或损坏时自动回退到静谧极光，并显示一次非阻断提示。
- 窗口位置恢复失败时使用默认右下角安全位置。
- 跨窗口事件发送失败不能损坏已经保存的皮肤状态；重新聚焦窗口时从 Rust 重新读取当前状态。

## 无障碍与抗打扰

- 球体按钮具有明确可访问名称、键盘焦点和展开状态。
- 展开面板支持 Tab 顺序、Escape 收回和焦点恢复。
- 所有图标按钮具有文字标签或可访问名称。
- 状态通过 `aria-live` 或 `role="alert"` 传达，不只依赖颜色和动画。
- 动画不闪烁，不依赖高频明暗变化，不抢占系统焦点。
- 悬浮窗启动显示，但不会自动展开、播放声音或弹出通知。
