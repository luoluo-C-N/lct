# 魔法影像库设计说明

## 目标与范围

首版是 Windows 桌面端的个人图片资料库。用户注册软件自带账号后，图片、导入文件与截图会同步至软件托管云端；同一账号可在后续移动端访问。首版不开发手机端。

产品同时覆盖灵感收集、素材管理与截图效率：导入已有图片，按时间线和相册浏览，支持收藏、标签、搜索；提供区域、当前窗口与全屏截图，完成轻量标注后保存。

## 已确认体验

- 固定在屏幕边缘的悬浮入口是可爱 furry 魔法记录使。平时有轻量待机动作，鼠标靠近时变为头像并展开命令。角色皮肤、动画和菜单作为独立模块，便于后续加入人类、精灵、兽娘、兽人或 furry 皮肤。
- 主资料库默认采用魔法书浏览。传统图库仍可切换，用于密集管理、批量整理和检索。
- 魔法书左侧为弧形日期流。滚轮或点击日期切换内容；当前日期高亮固定在日期栏视觉中段偏上，其余日期围绕它流动。日期只显示月/日和星期，不显示“今日”。
- 左上角月份入口不是普通下拉。点击后书册先合拢，用户选择一本月度影集，再从书脊位置展开；选择月份必须替换日期流和该月图片数据。
- 右侧是等尺寸叠页图片。默认较小并留出空间，悬停的图片向前突出、放大并出现柔和流动效果。多图时底部显示可拖动滑轨，指针在图片区滚轮也可浏览；只有一张图片时居中显示且隐藏滑轨。

## 信息与数据

每张资源包含：云端资源 ID、账户 ID、原始文件、预览图、创建/导入/截图时间、来源、相册、标签、收藏状态、同步版本和删除状态。截图另外记录截图模式与标注数据。

客户端以本地索引和缓存优先保证截图与浏览速度；后台队列上传资源和元数据。未联网时可继续截图、导入和整理，恢复网络后按队列同步。冲突以资源版本保留副本并提示用户处理，避免无声覆盖。

## 系统边界

Windows 客户端分为：悬浮角色与快捷键层、截图服务、资料库界面、图片索引与本地缓存、认证和同步客户端。云端分为：账号认证、资源对象存储、资源元数据 API、缩略图处理与同步版本服务。

截图服务和角色层不依赖具体资料库界面；它们通过“创建资源”接口写入本地索引，再由同步层上传。资料库只通过查询接口读取资源和修改元数据。

## 错误与安全

截图权限、磁盘不足、上传失败和认证过期必须显示明确可恢复状态。上传使用 HTTPS；服务端保存账户隔离的资源访问权限；客户端令牌使用操作系统安全凭据存储。删除先进入回收站，云端确认后再清理。

## 验证

测试覆盖截图模式、离线新增后恢复同步、上传失败重试、资源与标签搜索、月份切换后日期数据替换、日期流固定高亮、单图与多图书页状态、滑轨和滚轮浏览、窗口尺寸变化下的布局。

## 非目标

首版不包含手机端、滚动长截图、多人共享、第三方云盘连接或复杂图片编辑。
